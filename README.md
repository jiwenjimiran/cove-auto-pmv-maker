# Auto PMV Maker for Cove

Creates song-led PMVs from Cove videos using **DaVinci Resolve Studio** on the signed-in Windows desktop. With native Windows Cove, the extension starts its bundled companion automatically in the same desktop session. Docker uses the included external companion. Master video files are read in place; the companion only writes temporary audio and analysis data.

## Setup

3. In **Auto PMV Maker - Setup required**, click **Check Resolve**, then **Run Resolve compatibility check**. The job settings appear when both pass. 4. For Windows Docker, choose **External**, click **Download Windows companion**, extract it on the Resolve PC, and run `Start Companion Docker.cmd`.    Save the companion connection and mappings before browsing music or project folders. Choose output from Cove's video library tree.

The automatic mode uses the companion bundled with the installed extension, so updating the extension updates that companion. In external mode, update the companion ZIP after upgrading the extension. The companion ZIP is also published separately for PCs that cannot access Cove's settings page.

The current Cove UI needs [the included host patch](patches/cove-ui.patch) for performer/studio/tag/segment bulk actions and detail Videos-tab actions. It is already applied to the sibling `cove` checkout in this workspace; another sibling checkout can run `git apply ../cove-auto-pmv-maker/patches/cove-ui.patch` from its root, then rebuild the Cove UI. Installing the extension ZIP alone does not change Cove's own Segments selection bar.

The Resolve compatibility check is available from Cove settings after setup and after each Resolve version change. It checks the output format, duration, audio stream, and three-pane colors. Manual inspection of transition quality and beat timing is still needed before relying on the first Studio installation. The companion health endpoint checks scripting access and FFmpeg. Cove refuses to queue a render without a healthy companion or output folder, even when setup checks were skipped.

This is a preview release. The Resolve render and compatibility checks have been exercised with Studio 21.1.1.10; other versions require their own check.

## Current implementation notes

### 0.2.0 — automatic creative editing and comparison orders

Select scenes, open Create PMV, choose a song, and choose a layout/style. The editor automatically schedules clip effects around musical energy and onsets. Expand **Automatic effects** to individually disable musical pacing, beat punches, camera movement, impact recoil, speed ramps, motion echoes, highlight bloom, RGB accents, freeze accents, shot variety, action synchronization, movement matching, or color polish. Timing and intensity are automatic; detailed timing/output controls stay under Advanced.

Use **Add order to cart** to snapshot a version, change settings or the backing song, and add another. Edit/remove versions before **Process orders**. A cart supports up to 20 versions against the selected source scope. Each submission receives one persistent order number, and each version gets its own index: `PMVMAKER_ORDER42_name_1.mp4`, `PMVMAKER_ORDER42_name_2.mp4`. Imported outputs also receive a `PMVMAKER_ORDER42` tag. A `.settings.json` receipt beside each MP4 records settings, source ranges, music estimates, and planned effects. Choose the 25-second preview to compare quickly before a full-song order.

Orders preflight every version before queueing, retain each version's resolved sources, use a shared random seed for comparison, and run serially as one cancellable Cove job. Failed versions do not prevent remaining versions from rendering; the final job reports failures. Cancelling stops the current render and remaining versions. Uploaded songs are retained until the entire order exits. Retrying an accepted submission returns the original job while its receipt is available. Draft carts are local to the open dialog and are discarded by Cancel; use Cove Jobs to follow submitted work.

Effects operate on selected shot ranges before Resolve compositing, so they stay within pane masks. OpenCV performs motion analysis and image transforms; FFmpeg encodes high-quality H.264 intermediates and maps source audio through the same bounded retime. Resolve remains the final renderer, including hardware AV1 output. Generated media is temporary unless Save project is enabled. This processing adds render time and temporary disk use; source masters are never changed. Slow sections use frame blending, not neural Speed Warp. Music sections and action peaks are estimates, with restrained scheduling and cooldowns; optical-flow analysis is a motion cue, not semantic action recognition.

The compatibility check now includes three creative-effect fixtures (25 fixtures total). Re-run it after upgrading. The creative fixtures can also be run independently with `python companion/creative_smoke.py <fixture-output-folder>`.

- Resolve scripting and media import run in a separate worker process so long native calls do not block the companion's HTTP status endpoint. Sources enter Resolve in groups of 12, and Cove receives a heartbeat while a worker call is taking time.
- After each import, the worker refreshes Resolve's Media Pool and retries a small number of files that are still missing. A persistent import failure reports the missing paths and a sample returned path instead of dumping every Resolve clip property.

- Job submission compresses large source lists and retries transport interruptions with one request ID, so a lost reply cannot queue duplicate renders. Triple portrait matching first uses Cove's linked AI Faces detections and timestamped face boxes when they cover a candidate shot. If that evidence is sparse, it samples the video and compares faces with Cove face covers or performer portraits through SFace. AI Faces embeddings come from another model, so their scores are never compared with SFace scores; the similarity threshold applies to image matching only.
- Source selection supports videos, performers, studios, timed tags, and selected raw records mapped to their full displayed spans. Cove's resolved segment profile determines visible ranges, merged boundaries, and minimum duration; raw records are never used directly as PMV clip ranges. Include mode requires one or more timed segment tags. Exclude mode uses all visible full segments except selected tags. Either mode remains limited to the selected source and its filters. Videos with PMVMAKER in the title are excluded.
- The popup supports Cove audio search with selectable, playable results; a scrollable music-folder tree with track previews; direct audio-file upload; YouTube URL; and selected Cove video audio. A backing track must be selected before Create is enabled. Uploaded songs (up to 200 MB) are sent to the Windows companion, removed after the PMV job, or removed when the popup is cancelled. Per-job controls override saved defaults.
- Jobs are exclusive in Cove and serialized again in the companion. Cancellation propagates to FFmpeg and Resolve. Cove job progress names the video being analyzed, face detection when enabled, the clip being assembled, and brightness sampling when selected. The companion returns used video and segment IDs for metadata import.
- The companion sends ordered diagnostics to Cove's **Settings â†’ System Info â†’ Logs** under the `[PMV]` prefix. Logs include stage changes, scene windows, source rejections with elapsed time and rejection reasons, selected source and song ranges, pane numbers, performer names, and mean SFace similarity for accepted face matches. The displayed match confidence is a cosine similarity score, not a probability of identity. Cove also logs import completion and errors; the companion keeps a bounded event buffer until Cove polls it.
- AV1 MP4 is the default render codec; H.264 and H.265 remain selectable. AV1 requires a hardware encoder: Resolve AV1 or NVIDIA AV1 from a temporary DNxHR HQX render. No CPU encoder fallback is used. Layout checkboxes allow grid, triple portrait, and full screen; no selection means full screen. Full screen and grid use whole shots from eligible timed segments. Only triple portrait offers a Face slice, with optional matching against performers linked to the source video. Face matching uses bundled YuNet and SFace models and a configurable similarity threshold of at least 55%. The face crop preserves the full source height.
- Source selection uses only Cove full display segments after include or exclude filtering. Progressive sampling visits successive sections of those eligible segments. Timestamp limits and optional scene cycling are available in settings and per job. Performer gender presets use Cove metadata only; they do not infer gender from appearance.
- The advanced **Re-encode incompatible containers** option defaults on. For WMV/ASF sources, FFmpeg converts only selected ranges to H.264 MP4 clips before Resolve imports them. Source masters stay in place. Temporary clips are removed after the job; when Save project is enabled, the clips are kept beside the `.drp` so the project can reopen. Turning the option off excludes WMV/ASF sources in the Create preview.
- If Resolve rejects another source import, the worker probes only the rejected file. When a file named `.mp4` or `.mov` actually contains Matroska video in an MP4-compatible codec, FFmpeg stream-copies the selected ranges to real MP4 containers and retries their import. The source video codec is preserved, and only the selected ranges consume temporary space.
- Color matching defaults to None. Match brightness samples the first two seconds of each used video; Warm and Cool apply subtle channel shifts without that sampling step.
- Resolve's scripting API must be tested with a short render on the target Studio installation before relying on crop, scaling, grading, and compositing behavior. Use **Run Resolve compatibility check** in Cove settings to render all three styles, both original layouts, all source-audio modes, the grid, and both expansion transitions. It checks H.264/AAC output and samples cell colors.
- The Resolve adapter uses the current timeline-property API where available, retries a newly appended clip while Resolve initializes it, and sets project-level fill scaling so clips can inherit it if a per-clip scaling override is rejected. Any remaining property rejection identifies the video, track, timeline position, requested value, and Resolve's current value.

## Checks

Run `python -m unittest discover tests`, `python -m py_compile companion/*.py`, `dotnet run --project tests/PathChecks/PathChecks.csproj`, `dotnet run --project tests/EndpointChecks/EndpointChecks.csproj`, `dotnet run --project tests/LocalCompanionChecks/LocalCompanionChecks.csproj`, `dotnet build src/PmvMaker/PmvMaker.csproj`, and `cd frontend; npm run build`.

Resolve starts only when you create a PMV or explicitly run the compatibility check. Opening settings, checking connection status, and polling validation status never launch Resolve.
